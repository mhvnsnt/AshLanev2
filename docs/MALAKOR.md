## The Visual Formula (from owner's analysis)
- **90s CGI Render Style**: Old PC adventure games, screensavers, early Bryce 3D renders. Stiff shiny textures, dramatic lighting, slow-panning atmospheric shots.
- **Color Palette**: Pitch-black backgrounds × highly saturated neon purples, deep blues, glowing toxic greens.
- **Literal Asset Mashups**: Culture built INTO the models — diamond grill in a glowing sun's mouth, gold chains on a skeleton wizard holding a styrofoam cup.
- **Structured Worldbuilding**: Names the world, places text in renders, organizes with playlists ("Lore v1", "Og").
- **Surrealist Threat**: Slightly menacing — glowing eyes in dark, skulls, dark cathedrals, imposing figures staring at camera.
- **Pacing**: No fast cuts. Slow, heavy, nostalgic. High-contrast trap elements injected center-frame.

## The Pipeline (owner's reverse-engineering)
- AI-generated (not manual 3D): Midjourney/Stable Diffusion for base images → Luma/Kling/Runway for image-to-video pans
- Proof: text hallucinations, object fusion (grill melts into teeth), geometric inconsistencies
- Prompts blend: "PS1 graphics" + "low-poly 3D" + trap elements + dark fantasy subjects
