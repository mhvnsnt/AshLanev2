# Prototype imports

Reference material pulled from the retired **mhvnsnt/AshLane-prototype**
(original AshLane repo) on 2026-10-08. Nothing here is wired into the game.
Nothing here overwrites V2 work. This is an archive, not a dependency.

## Contents

- `PWA_PROOF/` — screenshots from the original repo's PWA proof
  (headless playthrough, Oct 2026): main menu, story/jobs, character
  customization, roster, combat arena, and Hollow combat frames.
- `screenshots/` — menu visual-overhaul screenshots from the original repo:
  proprietary SVG menu art, fighter portraits, card layouts.
- `shots/` — model pose renders (idle/punch) for CAIN_ELIAS_snakeskin,
  HOLLOW, and SOMBRA_NEGRA_rigged.
- `../assets/prototype/SOMBRA_NEGRA_rigged.glb` — Sombra Negra rig variant
  that existed only in the original repo. V2's `SOMBRA_NEGRA.glb` is the
  canonical model; this file is reference only.

## Provenance

Pulled non-destructively during the AshLane → AshLane-prototype retirement.
The prototype repo is kept for reference only; active development lives in
AshLanev2. If any of this material gets used, copy it out deliberately —
never import these paths directly.
