# Art Style References — Malakor / Shadow Wizard Money Gang

Owner-selected references for AshLane's general game art and menu art direction.
Reference-only — NOT game assets. Do not ship these images in the game.

## The Style
- Gritty urban theme MIXED with Malakor colors (neon purple/blue/green on dark)
- Hooded figures, gold chains, grill details — street culture in dark fantasy framing
- White-background piece: clean, striking, high-contrast character presentation

## Usage
- **Menu art / general game art**: Mix gritty urban + these colors + this composition style
- **Character cards**: Urban Reign / Tekken style (separate direction)
- **Buffalo Bill**: Hooded wizard art as reference — hood ON in some art, hood OFF revealing Bill Sabre underneath. Proprietary take, close to this style.
